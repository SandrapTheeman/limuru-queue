---

## PiP Modes

| Mode | Description |
|------|-------------|
| Top-Right | Queue overlay in corner |
| Bottom-Right | Queue overlay in corner |
| Sidebar | Queue on left/right edge |
| Split 70/30 | 70% TV, 30% queue |
| Split 60/40 | 60% TV, 40% queue |
